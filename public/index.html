                    ARQUITECTURA DEL PROYECTO
                    
¿Cómo funciona la conexión C → WebAssembly?

                    
El flujo completo desde el código fuente hasta la ejecución en el navegador.

                

            


            

                

                    01
                    
Código en C Modular

                    
La estructura Contacto, las funciones de inserción, edición, búsqueda y borrado se implementaron en contactos.c con validación estricta de memoria.

                

                

                    02
                    
Compilación con Emscripten

                    
El compilador emcc traduce el código C a bytecode de WebAssembly (proyecto.wasm) y genera el archivo pegamento (proyecto.js).

                

                

                    03
                    
Puente con JavaScript

                    
Mediante cwrap y ccall, JavaScript pasa cadenas y enteros directamente a la memoria lineal del módulo Wasm sin intermediarios.

                

                

                    04
                    
Interfaz Reactiva

                    
Cada interacción del usuario ejecuta funciones de C en microsegundos y los resultados de printf() se transmiten en vivo a la consola.
